How it works

Two onboard RGB views are the only input. The network lifts them into a bird's-eye frame and predicts three fields — where the target is (T), where the frozen policy would succeed from (S), and what is traversable (C). A geodesic controller turns those into a single potential P, and the robot climbs it.

Same start, three systems

These are cells from the 120-seed campaign where ASCENT succeeded and both baselines failed from the identical start pose — the three clips below are the same pose, the same scene, the same frozen π0.5, filmed from one fixed room camera. N2M predicts a single stance and goes to it; π0.5 alone never repositions at all.

N2M outputs a stance, not a path, so its evaluation teleports; here the base is interpolated along the straight line to that same stance, which leaves the outcome unchanged. π0.5 action sampling is stochastic, so a single rollout can differ from the campaign average; every cell shown here was re-run and kept only if the baseline failure reproduced each time.
